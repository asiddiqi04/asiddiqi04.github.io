Hackathon Project

GreenScore

Barcode scanner + search that estimates ethical and sustainability scores for consumer products using a RAG pipeline and AI-assisted scoring. Built with friends during a hackathon.

  • React frontend with modern UI + Tailwind; FastAPI backend.
  • Data sources: UPCItemDB & Open Food Facts; MongoDB persistence.
  • AI: Gemini for score rationales; vector search for retrieval.
  • Features: scan/search history, favourites, and an in-app AI helper.

Personal Fitness App · Work in Progress

ShadowBoxer

Personal fitness web app that detects punches and tracks combos using webcam pose estimation. Building timed rounds, scoring, and gamified workouts next.

  • MoveNet pose detection with TensorFlow.js; real-time canvas overlay.
  • Jab detection + counter implemented; combo logic in development.
  • Responsive UI with Tailwind; Vite build for fast iteration.
  • Planned: streaks, leaderboards, and coach-style feedback.
